# Zuno — Gestão de Atividades, Empresas e Horas

Sistema de controle de horas e agenda em tempo real conectado à nuvem do **Supabase** (Projeto: *Agente de IA*).

## Tecnologias
- HTML5 / CSS3 / JavaScript (Vanilla)
- Supabase Database (Postgres)
- Supabase Realtime (WebSockets)
- Vercel Deployment

## Como rodar localmente
Abra `index.html` em qualquer navegador moderno.
